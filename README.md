# Многостраничный сайт

Простой, но адаптивный многостраничный сайт на HTML и CSS. Подходит как шаблон для портфолио, лендинга или небольшого корпоративного сайта.

## Что внутри

- `index.html` — главная страница с секцией «Услуги».
- `about.html` — страница «О нас» с перечнем направлений работы.
- `contacts.html` — страница «Контакты» с формой обратной связи.
- `style.css` — общие стили и адаптивная вёрстка.

## Особенности

- Адаптивность под мобильные устройства.
- Единая шапка и подвал на всех страницах.
- Подсветка активного пункта меню.
- Семантическая разметка (header, main, footer, section).

## Как запустить

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` в браузере.
3. При необходимости отредактируйте тексты и ссылки.
